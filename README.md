# NumPy Data Explorer

## 📌 Project Overview

NumPy Data Explorer is a Python-based project created to learn and demonstrate the fundamental features of NumPy.

This project covers array creation, indexing, slicing, mathematical operations, statistical operations, axis-wise operations, reshaping, broadcasting, saving and loading NumPy arrays, and performance comparison between Python lists and NumPy arrays.

## 🎯 Objectives

* Learn NumPy fundamentals.
* Create and manipulate NumPy arrays.
* Perform mathematical and statistical operations.
* Understand indexing and slicing.
* Perform row-wise and column-wise operations.
* Understand reshaping and broadcasting.
* Save and load NumPy arrays.
* Compare the performance of Python lists and NumPy arrays.

## 🛠️ Technologies Used

* Python
* NumPy

## 📚 Concepts Covered

### 1. Array Creation

Created NumPy arrays using functions such as:

* `np.array()`
* `np.zeros()`
* `np.ones()`
* `np.arange()`

### 2. Indexing and Slicing

Accessed individual elements and selected portions of NumPy arrays using indexing and slicing.

### 3. Mathematical Operations

Performed:

* Addition
* Subtraction
* Multiplication
* Division
* Square
* Square root

### 4. Axis-wise Operations

Performed calculations across rows and columns using:

* `axis=0`
* `axis=1`

### 5. Statistical Operations

Used NumPy functions for:

* Mean
* Median
* Standard deviation
* Minimum
* Maximum
* Sum

### 6. Reshaping

Changed the shape of arrays using the `reshape()` function.

### 7. Broadcasting

Applied operations between arrays and individual values using NumPy broadcasting.

### 8. Save and Load

Saved NumPy arrays using `np.save()` and loaded them using `np.load()`.

### 9. Performance Comparison

Compared the execution time of Python list operations with NumPy array operations.

## ⚙️ Installation

First, make sure Python is installed on your system.

Install NumPy using:

```bash
pip install numpy
```

Or install the required package using:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Open the project folder in VS Code and run:

```bash
python numpy_data_explorer.py
```

The program will demonstrate different NumPy operations and display the results in the terminal.
